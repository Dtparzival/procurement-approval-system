# Agent 智簽公文 使用指南

歡迎使用 Agent 智簽公文系統！本指南將引導您快速上手，並充分利用各項功能，大幅提升您的行政效率。

## 1. 系統簡介

Agent 智簽公文是一個專為國泰金控打造的智能公文生成系統。您可以透過自然語言描述採購需求，系統將自動為您生成專業、符合格式的採購簽呈，節省您 99% 的公文撰寫時間。

## 2. 核心功能

### 2.1. 生成簽呈

這是系統最核心的功能。您只需要在「採購需求描述」的輸入框中，詳細填寫您的需求，AI 就會為您產出簽呈。

**操作步驟**：
1.  在「採購需求描述」輸入框中，填寫您的需求，內容應包含：
    *   **品項名稱**：例如「筆記型電腦」、「辦公椅」
    *   **數量**：例如「10 台」、「5 張」
    *   **規格需求**：例如「Intel Core i7 處理器、16GB 記憶體」
    *   **預算**：例如「每台約 NT$ 35,000」
    *   **用途**：例如「供業務部門同仁外出辦公使用」
2.  點擊「生成簽呈」按鈕。
3.  系統會進入讀取狀態，並在右側「生成結果」區塊顯示產出的簽呈內容。

### 2.2. 上傳參考文件

如果您有相關的參考文件（例如：產品型錄、報價單、需求規格書），可以上傳給 AI 參考，讓生成內容更精準。

**操作步驟**：
1.  點擊或拖曳檔案到「參考文件」區塊。
2.  系統支援 PDF、Word、圖片等格式，單一檔案大小上限為 10MB。
3.  上傳成功後，AI 會在生成簽呈時自動參考文件內容。

### 2.3. 草稿管理

系統提供完整的草稿管理功能，方便您隨時儲存、載入或刪除編輯中的簽呈。

*   **儲存草稿**：點擊「儲存草稿」按鈕，系統會將當前輸入的「草稿標題」和「採購需求描述」儲存起來。
*   **查看草稿**：點擊「查看草稿」按鈕，會彈出草稿列表，您可以選擇載入或刪除過去的草稿。
*   **自動儲存**：在「設定」中開啟「自動儲存草稿」功能後，系統會在您輸入時自動儲存，防止內容遺失。

### 2.4. 編輯、複製與下載

簽呈生成後，您可以進行後續處理。

*   **編輯簽呈**：點擊「編輯」按鈕，可以直接修改生成結果。
*   **複製內容**：點擊「複製」按鈕，可以將簽呈的純文字內容複製到剪貼簿。
*   **下載 PDF**：點擊「下載」按鈕，系統會將簽呈轉換為 PDF 格式供您下載保存。

## 3. 系統設定

點擊右上角的「設定」按鈕，可以進行以下設定：

*   **API Key**：輸入您的 AI 服務 API Key。
*   **AI 模型**：選擇您要使用的 AI 模型版本。
*   **自動儲存草稿**：開啟或關閉自動儲存功能。

## 4. 錯誤處理與協助

當系統發生錯誤時，會顯示對應的錯誤訊息。您可以根據錯誤訊息進行操作，或參考我們整理的 [錯誤代碼清單](docs/ERROR_CODES.md) 以了解詳情。

如果問題持續發生，請隨時透過「聯絡技術支援」與我們聯繫。
