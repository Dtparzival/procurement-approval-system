# Agent 智簽公文 - 錯誤代碼清單

本文件列出系統中所有錯誤代碼及其對應的中文訊息，方便日後維護和更新。

## 錯誤代碼格式說明

錯誤代碼採用以下格式：`{類別}_{編號}`

- **API**: API 相關錯誤
- **NET**: 網路相關錯誤
- **FILE**: 檔案相關錯誤
- **AUTH**: 認證相關錯誤
- **INPUT**: 輸入驗證相關錯誤
- **UI**: 使用者介面相關錯誤

---

## API 錯誤 (API_*)

| 錯誤代碼 | HTTP 狀態碼 | 標題 | 描述 | 使用場景 |
|---------|------------|------|------|---------|
| API_401 | 401 | API Key 無效 | 請在設定中更新 API Key。 | API Key 無效或已過期 |
| API_429 | 429 | 請求過於頻繁 | 請稍等幾分鐘後再試。 | 請求次數超過限制 |
| API_500 | 500 | AI 服務暫時無法使用 | 請稍後再試，或聯絡技術支援。 | 伺服器內部錯誤 |
| API_502 | 502 | AI 服務暫時無法使用 | 請稍後再試，或聯絡技術支援。 | 閘道錯誤 |
| API_503 | 503 | 服務維護中 | 系統正在進行例行維護，請稍後再試。 | 服務暫時不可用 |
| API_UNKNOWN | - | 產生失敗 | 請稍後再試。 | 其他未知 API 錯誤 |
| API_PARSE_ERROR | - | 產生失敗 | 請稍後再試，或聯絡技術支援。 | API 回應格式錯誤 |
| API_EMPTY_RESPONSE | - | AI 無法生成內容 | 請提供更詳細的採購需求描述後再試。 | AI 生成內容為空 |

| FILE_WORD_EXTRACT_ERROR | Word 處理失敗 | 無法提取 Word 文本。 | Word 文字提取失敗 |
| FILE_PROCESS_ERROR | 檔案處理失敗 | 檔案處理失敗，請重新上傳。 | 一般檔案處理錯誤 |

| 錯誤代碼 | 標題 | 描述 | 使用場景 |

## 維護說明

1. 新增錯誤代碼時，請遵循命名規則：`{類別}_{編號或描述}`
2. 每個錯誤代碼必須包含：標題、描述、使用場景
3. 修改錯誤訊息時，請同步更新 `js/messages.js` 配置檔案
4. 重大變更請更新「更新紀錄」區塊
