## 🔍 已知問題

### 核心功能測試中的已知問題

1. **瀏覽器剪貼簿讀取限制**
   - 問題：在自動化測試環境中，`navigator.clipboard.readText()` 可能因為安全限制無法讀取剪貼簿內容
   - 影響：僅影響自動化測試，實際使用不受影響
   - 解決方案：已通過手動檢查 `textContent` 屬性確認複製功能正確實作

2. **刪除草稿的確認對話框**
   - 問題：在自動化測試環境中，`confirm()` 對話框可能被自動取消
   - 影響：僅影響自動化測試，實際使用不受影響
   - 解決方案：已通過直接調用 `Storage.deleteDraft()` 確認刪除功能正常運作

### UI/OAuth 測試中的已知問題

1. **Google Client ID**
   - 問題：index.html 中使用佔位符 `YOUR_GOOGLE_CLIENT_ID`
   - 影響：無法完成實際的 Google 登入
   - 解決方案：參考 `GOOGLE_OAUTH_SETUP.md` 建立 Google Cloud 專案並取得 Client ID

2. **Google Sign-In 按鈕語言**
   - 問題：按鈕文字顯示為西班牙文
   - 影響：僅影響視覺，不影響功能
   - 解決方案：這是 Google Identity Services 的預設行為，會根據用戶瀏覽器語言自動調整
